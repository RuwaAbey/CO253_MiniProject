# Contact Management System

## Overview
This is a simple **Contact Management System** developed in the C programming language. It allows users to manage contacts by performing operations such as adding, listing, searching, editing, deleting, and deleting all contacts. Contact information is stored in a text file (`contact.txt`) for persistence.

## Features
- **Add a New Contact**: Add a new contact with a unique name, phone number, address, and email.
- **List All Contacts**: Display all contacts in a tabular format.
- **Search for a Contact**: Search for a contact by name or phone number.
- **Edit a Contact**: Modify the details of an existing contact.
- **Delete a Contact**: Remove a specific contact by name.
- **Delete All Contacts**: Clear all contacts from the system.
- **User Guidelines**: Display instructions and constraints for using the system.

## Requirements
- A C compiler (e.g., GCC) to compile and run the program.
- Windows operating system (due to the use of `conio.h` and `Sleep` function).
- The program creates and uses a `contact.txt` file in the same directory as the executable for storing contact data.
